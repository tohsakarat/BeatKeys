# 动次打次 · BeatKeys（声控快捷键）

Windows 本地图形界面工具。通过录制自己的发音样本匹配命令，匹配通过后自动发送对应的键盘快捷键。

主要用于绘图、建模或高频快捷键场景（如数位屏作画时代替频繁手按 `Ctrl+Z`、`Ctrl+T`、`Alt+Delete` 等）。

与常见“语音转文字（ASR）”工具的区别：
- **不进行文字转写**：直接提取音频的声学特征（MFCC）与本地录音样本比对，不受普通话标准度、同音字或词表限制。
- **完全本地运行**：计算全部在本机完成，不依赖云端 API，不加载庞大的神经网络模型，低延迟，低资源占用。
- **识别与执行队列隔离**：连续说话触发多次相同命令时，按实际识别次数依次排队发送，不会丢失按键。
- **保护隐私**：音频数据与配置均保存在本地，不向任何外部网络上传。

## 使用指南

### 1. 运行
- **普通用户**：从 [Releases 页面](https://github.com/tohsakarat/BeatKeys/releases) 下载 `BeatKeys.exe`，直接双击运行，无需安装 Python 或额外环境。
- **源码运行**：双击 `run.bat`，首次会自动创建虚拟环境并安装运行依赖。

### 2. 检查麦克风
1. 在顶部“麦克风”下拉框中选择当前使用的麦克风设备。
2. 点击 **测试麦克风**，观察电平条与状态指示：
   - 绿色：正常收音。
   - 黄色：音量低于起音门槛或近乎静音。
   - 红色：输入过大削波失真。

### 3. 录制声音样本
程序内置了绘图常用的 10 项命令预设（撤销、重做、自由变换、新建图层、填充选区、套索、吸管、画笔等）：
1. 在左侧命令列表中选中一项。
2. 在右侧面板点击 **录制首个样本**（已有录音时为 **再录一个样本**）。
3. 提示就绪后，以正常语速读出口令。说完后稍等自动停止并保存；也可以点击 **录完** 提前截取（程序会自动裁除首尾多余静音）。
4. **建议**：每个常用命令录制 2~3 个样本（如正常语速、快速、轻声），以覆盖实际使用时的发音起伏。

### 4. 开始监听
- 点击底部的 **开始监听**。
- 切回绘图或目标软件，说出口令后程序会自动触发对应快捷键。
- 也可以在“设置”页中录入**启停快捷键**，方便在全屏作画时随时全局开启或关闭监听。

## 命令与样本管理

主界面上方为主操作区，下方为滚动日志区；中间的分界条可鼠标上下拖动调节高度。

- **新建命令**：填写显示名称与**英文 ID**。英文 ID 只能包含小写英文字母和 `-`（如 `undo`、`fill-selection`），不可重复。点击“录入快捷键”并在键盘上按下组合键即可自动录入。
- **编辑命令**：可修改命令名称、快捷键或英文 ID。修改英文 ID 后，本地录音文件夹会同步重命名，已有录音保留。
- **排序**：在空闲状态下，按住列表中的命令上下拖动即可排序，松开后自动保存顺序。
- **试听与删除**：右侧列表可选中单个录音样本进行试听播放或删除；点击 **清空** 可一次性删除当前命令的所有录音。
- **扩展键支持**：发送层针对 Windows 独立 `Delete` 键、方向键、`Insert`、`Home`、`End`、`PageUp`、`PageDown`、右侧 `Ctrl`/`Alt` 等扩展键做了标志位处理，确保 Photoshop 前景色填充（`Alt+Delete`）等组合键正常生效。

## 匹配机制与调试

- **试匹配**：只比对录音与特征距离，不发送按键。日志输出匹配命令与计算耗时，“调试”页可查看各命令的具体 DTW 距离。
- **开始监听**：采集分段、识别与按键执行三者独立运行。完整声段按时间顺序进入识别队列，匹配通过后进入按键队列。
- **匹配原理**：提取归一化 MFCC 特征，利用子序列 DTW（动态时间规整）在声段中滑动查找匹配，容忍语速快慢变化。距离低于阈值（当前默认 1.1）视为命中。

## 参数设置

在 **设置** 页中可根据实际使用环境微调（修改后点击“保存设置”）：

- **录音保存目录**：默认位于当前系统用户目录下的 `.beatkeys/samples`，可自定义到其他绝对路径。
- **启停快捷键**：全局快捷键，松开按键时生效；空闲时按下开始监听，监听时按下停止。
- **发音容错程度**（阈值）：数值越大越容易匹配，但过大可能增加误触风险；数值越小越严格。
- **开始收音的音量**：达到该音量时开始捕获声音；环境吵闹可调大，轻声说话可调小。
- **视为安静的音量**：低于该音量时判定为说话暂停，不能高于开始收音音量。
- **说完后等待（秒）**：说完口令后持续安静多久判定为一句话结束并开始匹配；调短可加快响应速度。
- **最短 / 最长说话时长（秒）**：过滤太短的声音干扰，达到最长时长强制切分。
- **两次按键间隔（秒）**：两次快捷键发送之间的最小冷却时间，防止单次口令误触发重复按键。

## 数据存储与隐私

- 配置文件路径：`C:\Users\你的用户名\.beatkeys\config.json`
- 录音样本路径：`C:\Users\你的用户名\.beatkeys\samples\<command-id>\*.wav`
- 声音属于个人敏感生物特征，录音文件以标准 WAV 格式保存在本地，未加密。
- 请勿将个人录音目录上传到公共网盘或代码仓库；与他人分享日志或排查问题时，避免包含个人录音文件。

## 项目结构与开发者说明

### 核心代码模块
- `gui.py`：Tkinter 主界面、命令管理、样本管理与会话调度。
- `audio_widgets.py`：波形绘制组件与快捷键捕获对话框。
- `audio_session.py`：设备采集、分段、识别与按键执行的独立线程与队列调度。
- `audio_listener.py`：音频设备枚举、底层数据流采集与驱动健康状态监控。
- `speech_segmenter.py`：基于 RMS 能量的语音起止点检测与分段。
- `audio_features.py`：MFCC 特征提取与 DTW 距离计算。
- `similarity_recognizer.py`：多模板子序列匹配与去重排队。
- `sample_store.py`：WAV 样本读写与命令文件夹重命名管理。
- `keyboard_controller.py`：Windows 原生按键事件与扩展键模拟。
- `user_data.py`：用户目录初始化、首次预设加载与配置存储。

### 自行打包 Windows EXE
在安装好 Python 环境的 Windows 环境下执行：
```bat
.venv\Scripts\python.exe -m pip install pyinstaller==6.22.2 pillow==12.3.0
.venv\Scripts\python.exe build_exe.py
```
打包产物位于 `dist/BeatKeys.exe`，已配置单文件绿色运行并集成猫头图标。
