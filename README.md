# 动次打次 · BeatKeys

> **解放双手，动嘴即按键。**  
> 专为画师、修图师、建模师及高频快捷键用户设计的**完全本地运行的声控快捷键小工具**。

你在数位屏、数位板或画布前画画修图时，是否经常觉得左手悬在键盘上按 `Ctrl+Alt+Z`、`Ctrl+T`、`Alt+Delete` 很别扭，甚至手腕发酸？  
**动次打次（BeatKeys）** 让你用最自然的方式控制电脑：张嘴念一声“撤销”、“图层”、“套索”甚至一句短促的口令，程序就会立刻替你自动按下对应的键盘快捷键！

---

## ✨ 为什么它与众不同？

很多朋友一提到“语音控制”，首先想到的是手机语音助手那种“语音转文字（ASR）”。但在高频生产力场景下，语音识别往往非常鸡肋：

1. **纯本地秒级比对，零延迟，零上传**：不调用任何云端接口，不吃显卡算力，也不需要动辄几个 G 的大模型，极低内存与 CPU 占用，老电脑也能秒开。
2. **认发音，不认文字（声调与波形匹配）**：普通话不标准？方言发音？同音字容易搞混？统统没关系！甚至你不想说话，只想发出“啪”、“咔”、“滴”的一声或者口哨声，只要提前录制过这个声音，它就能精准识别。
3. **快速连读不丢指令**：连着快速说“撤销、撤销”，识别队列与键盘执行队列完全独立，说了几次就稳妥按下几次，绝不漏按。
4. **真正的隐私安全**：所有的发音比对和配置都在你本地机器上完成，绝不向外传输任何声音数据。

## 🚀 极速上手指南（三步开工）

### 1. 下载并运行
直接前往 [GitHub Releases](https://github.com/tohsakarat/BeatKeys/releases) 页面，下载最新的 `BeatKeys.exe`。  
绿色免安装，单文件双击直接运行，**无需配置 Python 或任何开发环境**。

### 2. 挑选麦克风与测试
1. 在软件顶部的“麦克风”下拉框中选择你的输入设备。
2. 点击 **测试麦克风**，对着麦克风说几句话，观察上方的电平条与状态圆点变为绿色，确认收音正常。

### 3. 录入你的专属发音
软件已贴心内置了画画最常用的 10 个 Photoshop / 绘画快捷键（撤销、重做、自由变换、新建图层、填充选区、套索、吸管、画笔等）：
1. 在左侧列表中点击选中一个命令（例如“撤销一步”）。
2. 在右侧面板点击 **录制首个样本**。
3. 状态提示就绪后，自然地说出你的口令（例如“撤销”）。
4. 停顿片刻程序会自动保存；如果想提前结束，点击 **录完** 即可（会自动帮你掐头去尾保留有效发音）。
> 💡 **发音小技巧**：建议为高频指令录入 2~3 个样本（比如一口气录一个快速的、一个常速的、一个轻声的），识别率会极其坚挺！

### 4. 开启监听，开画！
点击界面下方的 **开始监听**（或者按下你自定义的**全局启停快捷键**），切回你的绘画/设计软件，享受动嘴就能撤销与换工具的畅快体验！

## 🛠️ 实用特性

- **快捷键一键录入**：新建或编辑命令时，只需点击“录入快捷键”并在键盘上自然按下组合键，程序自动捕获，无需手动敲键名。
- **完美支持系统扩展键**：特别适配了绘图软件的前景色填充快捷键（`Alt+Delete`），以及方向键、`Insert`、`PageUp` 等特殊键位。
- **清晰的英文 ID 与文件夹结构**：每个命令都拥有清晰的小写英文 ID（如 `undo`、`brush`、`fill-selection`），录音文件夹会自动按 ID 归类，修改 ID 时录音文件夹同步自动改名，文件整整齐齐。
- **鼠标拖动灵活排序**：命令列表支持按住鼠标直接上下拖拽排序，常用指令随心排。
- **通俗直观的调参面板**：
  - **发音容错程度**：觉得识别不敏感就往大调，觉得老是误触发就往小调。
  - **开始收音音量 / 视为安静音量**：环境吵闹就提高收音门槛，夜深人静可以调低捕捉轻声细语。
  - **说完后等待时间**：口令说完后隔多久触发按键，想要极致触发速度可适当改短。

## 🔒 隐私与个人数据说明

声音属于个人的敏感生物特征：
- 软件的本地配置保存在系统用户目录：`C:\Users\你的用户名\.beatkeys\config.json`。
- 录音样本保存在本地：`C:\Users\你的用户名\.beatkeys\samples`（可在设置中随时更换到其他盘符）。
- **本软件承诺绝不上载任何录音数据至互联网。**
- 向他人分享错误日志、截图或排查问题时，请留意不要将包含个人真实声纹的原始 WAV 音频随同打包发送。

## 💻 开发者与源码构建

如果你想二次开发、调整算法或自己打包项目：

### 技术栈与算法路线
- **声学特征**：MFCC（梅尔频率倒谱系数），每帧 10ms，提取音色与音调信息。
- **距离对齐**：子序列 DTW（Dynamic Time Warping，动态时间规整），计算与样本特征序列的均方根对齐距离，天然容忍说话语速快慢变化。
- **并发隔离**：音频采集分段、DTW 识别以及按键模拟三者分别位于独立线程与队列中。

### 本地运行
```bat
:: Windows 环境下克隆并一键启动
git clone https://github.com/tohsakarat/BeatKeys.git
cd BeatKeys
run.bat
```

### 自行打包 Windows EXE
```bat
.venv\Scripts\python.exe -m pip install pyinstaller==6.22.2 pillow==12.3.0
.venv\Scripts\python.exe build_exe.py
```
打包脚本已配置好窗体猫头图标，并自动剔除多余实验缓存，生成单文件绿色版 `dist/BeatKeys.exe`。
